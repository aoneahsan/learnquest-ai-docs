# For Teachers

**The teacher dashboard turns LearnQuest AI into a classroom tool** — create a class, assign learning,
and review how each student is doing, all in one place.

## Getting started

1. Create a **teacher** account (see [Create an account](/getting-started/create-account)).
2. Open the teacher dashboard.
3. Create a class and add students.
4. Assign activities or [learning paths](/features/learning-paths).

## What teachers can do

| Capability | What it means |
|------------|---------------|
| **Create classes** | Organise students into groups. |
| **Assign activities** | Hand out specific activities or paths to a class or student. |
| **Review progress** | Open a student's detail view to see completed work and scores. |
| **Track the class** | Use the dashboard to see how the whole class is progressing. |

## In the classroom

- Assign a **quiz** as a warm-up and review the class's scores afterward.
- Set a **learning path** as ongoing homework so students always know what's next.
- Use the **student detail** view during conferences to discuss a child's progress with a parent.

## Works with the rest of the app

Teacher assignments feed the same [progress tracking](/guides/track-progress) and
[gamification](/features/gamification) that students see everywhere else, so classroom work and
independent learning reinforce each other.
