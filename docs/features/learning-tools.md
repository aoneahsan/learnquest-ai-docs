# Learning Tools

**A learning tool in LearnQuest AI is a focused, single-purpose utility a learner can open on its own
— separate from the activity library.** There are 50 tools in total, covering math, language,
science, creativity, and study skills. Every tool runs in the browser; the few that fetch live data
use **free, no-key public APIs**, so there is nothing to pay for and no key to configure.

## Honest framing

Tools that need live information call **free public APIs that require no key** — Open-Meteo (weather),
MyMemory (translation), Datamuse (rhymes), and the free dictionary API. Tools like the spelling bee
and phonics use the browser's built-in speech feature. Everything else is pure on-device logic. There
is no paid AI service behind these tools, which is why the whole app stays free.
