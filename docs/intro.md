# Introduction to LearnQuest AI

**LearnQuest AI is a free, gamified learning app for children ages 1–15.** It combines hundreds of
interactive activities, 50 standalone educational tools, guided learning paths, and a motivating
gamification system into one app that works in the browser and on Android — at no cost.

This documentation explains what LearnQuest AI does, how to get started, and how each feature works.
It is written to be honest about what the app is (and is not), so parents, teachers, and curious
learners always know what to expect.

## What you can do

- **Play and learn** with quizzes, puzzles, memory games, coloring, story reading, math problems,
  and coding challenges, organised by age band and subject.
- **Use 50 learning tools** such as a graphing calculator, chemistry equation balancer, periodic
  table, dictionary, translator, spelling bee, and mind map — each runs right in the browser.
- **Stay motivated** with badges, daily streaks, leaderboards, and teams.
- **Follow learning paths** that build a skill step by step.
- **Track progress** for yourself, your child, or your class.

## Who it is for

| Role | What LearnQuest AI gives you |
|------|------------------------------|
| **Kids (1–15)** | A safe, colourful place to learn through play, with instant feedback and rewards. |
| **Parents** | A parent portal to link a child account, set controls, and follow progress. |
| **Teachers** | A teacher dashboard to create classes, assign activities, and review student results. |

## How it is built

LearnQuest AI is a React + Capacitor application backed by Firebase. The web app is an installable
Progressive Web App (PWA), and the same codebase ships to Android. Many activities and tools work
offline and sync when a connection returns.

:::note Honest framing on "AI"
"AI" in the name is part of the product brand. The educational tools work using **on-device logic
and free, no-key public APIs** (for example, Open-Meteo for weather, MyMemory for translation, and
Datamuse for rhymes). They do **not** rely on a paid large-language-model service, so there are no
usage fees and the app stays free.
:::
