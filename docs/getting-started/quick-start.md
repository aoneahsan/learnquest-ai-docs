# Quick Start

**This guide gets you from sign-in to your first completed activity in about five minutes.** No setup
is required beyond a free account.

## 1. Open the app

Open the [web app](https://learnqai.aoneahsan.com) in any modern browser, or install the Android
app from [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.learnquest). The
web app is installable too — your browser may offer an **Install** option for an app-like experience.

## 2. Browse activities

Go to **Browse**. Activities are organised by subject and age band. Use the filters and search to
narrow things down — for example, "math" for a 6-year-old, or "reading" for a 10-year-old. Each card
shows the activity title, type, and age range.

## 3. Play an activity

Tap any activity to open it. Depending on the type you'll see:

- **Quiz** — multiple-choice questions with instant feedback and a score.
- **Puzzle** — drag-and-drop pieces into place.
- **Memory game** — flip cards to find matching pairs.
- **Coloring / drawing** — paint on a canvas with colours and brushes.
- **Story** — read pages with optional read-aloud narration.
- **Math problem** — solve step by step.
- **Coding challenge** — write and test small programs.

Finish the activity to record a score and the time you spent.

## 4. Earn rewards

Completing activities earns **badges** and builds a **streak**. Check the
[gamification](/features/gamification) page to see how badges, streaks, and leaderboards work.

## 5. Try a learning tool

Open **Browse → Tools** (or visit a tool directly) to try one of the 50 standalone tools — for
instance the **Graphing Calculator**, **Spelling Bee**, or **Periodic Table**. See the full list on
the [Learning Tools](/features/learning-tools) page.

## What's next

- Set up a [learning path](/features/learning-paths) for a focused goal.
- Parents: link your child in the [parent portal](/features/parents).
- Teachers: create a class in the [teacher dashboard](/features/teachers).
- See how to [track progress](/guides/track-progress) over time.
